# SilcL 引擎

基于 Rust 的 3D 几何建模引擎，支持群操作、代数结构、实时 3D 渲染。

## 技术栈

| 类别 | 技术 |
|------|------|
| 语言 | Rust |
| 图形渲染 | wgpu |
| 窗口管理 | winit |
| 数学库 | cgmath |
| 图形界面 | egui（二期完善） |
| 文档导出 | LaTeX |

## 项目状态

- 一期：核心模块已完成（数学内核、重置器、操作管理器、抽象数学计算器、算法编辑器、3D 渲染、键盘控制）
- 当前版本：v0.2.0
- 已知问题： egui UI 应环境兼容问题暂未显示
